# regex_bak

SillyTavern 正则预设行为修复扩展（外置，不改酒馆源码）。仓库根目录即扩展本体；根因分析与方案文档仅存本机，不入库。

## 它解决什么问题

官方「正则预设」切换时会把全局、局部（角色卡内）、预设内嵌（聊天预设文件内）三类正则中"不在清单里的"批量写成关闭并**写进角色卡/预设文件**，导致局部和预设正则莫名失效。本扩展接管官方控件，切换时**只同步全局正则**，角色卡与预设文件从此不会被它改写；另附体检面板，把历史上已被写坏的数据扫描出来、勾选恢复（恢复前自动备份进浏览器 IndexedDB，每来源只留最近一次，不下载文件）。

## 安装

把整个文件夹（含 manifest.json）拷贝/克隆到 `SillyTavern/public/scripts/extensions/third-party/regex_bak`，刷新页面，在扩展面板里启用。

## 使用

- **正则面板 → Regex Presets**：新建 / 保存 / 切换行为与官方一致，但只影响全局正则；每次切换 toast 提示开了几条、关了几条；有手动改动未保存时弹窗询问（保存并切换 / 丢弃并切换）。
- **正则面板 → regex_bak 存量体检**：点扫描，勾选要恢复的正则，点"恢复勾选项"；每个来源旁可"还原到此备份"。扫描/恢复时请勿同时编辑对应角色或预设。

## 注意

- 体检备份存在浏览器 IndexedDB（`regex_bak_backup` 库），清除浏览器数据会丢失备份。
- 官方"删除正则预设"按钮未拦截（本身无破坏性），行为保持官方。
