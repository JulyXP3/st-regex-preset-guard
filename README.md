# regex_bak

SillyTavern 正则预设行为修复扩展（外置，不改酒馆源码）。仓库根目录即扩展本体。

## 它解决什么问题

官方「正则预设」切换时会把全局、局部（角色卡内）、预设内嵌（聊天预设文件内）三类正则中"不在清单里的"批量写成关闭并**写进角色卡/预设文件**，导致局部和预设正则莫名失效（本机上由 cocktail 扩展的 regex-refresh-optimizer 抢先执行）。本扩展在 window 捕获阶段接管官方控件，切换时**只同步全局正则**，角色卡与预设文件从此不会被它改写。

## 安装

把整个文件夹（含 manifest.json）拷贝/克隆到 `SillyTavern/public/scripts/extensions/third-party/regex_bak`，刷新页面（更新扩展后需 Ctrl+F5，酒馆加载扩展 CSS/JS 不带版本号，浏览器会缓存），在扩展面板里启用。

## 使用

本扩展没有任何界面，装上即生效：

- **正则面板 → Regex Presets**：新建 / 保存 / 切换行为与官方一致，但只影响全局正则；每次切换 toast 提示开了几条、关了几条；有手动改动未保存时弹窗询问（保存并切换 / 丢弃并切换）。
- 局部（角色卡）与预设内嵌正则的开/关完全归你手动管理，正则预设切换永远不碰它们。

## 注意

- 被误关的局部/预设内嵌正则可手动恢复：切到对应聊天预设，在正则面板"预设内嵌正则"区用官方批量全选 + 批量启用即可。
- 被删除的正则无法找回（酒馆无版本历史）；如需防删除，需另行做文件级快照备份。
- 历史 v1.0.x 曾内置"存量体检"面板，因对实际使用场景属过度设计，自 v1.1.0 移除（旧代码在 Git 历史）。
